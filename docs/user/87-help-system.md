# Help System

## Overview

GCodeKit6 includes a built-in help system with documentation for all features, accessible directly from the application.

## Accessing Help

- **Help menu** — Open the help browser from the application menu
- **Help buttons** — Many panels and CAM tools have a Help button that opens context-sensitive help for that feature
- **Keyboard** — Use the configured help shortcut (see [Settings](70-settings.md))

## Help Browser

The help browser displays markdown-formatted documentation topics:

- **Topic list** — Browse all available help topics
- **Navigation** — Click links within topics to jump to related documentation
- **Cross-references** — Topics link to related topics using `help:topic_id` links

## Available Topics

The topic list shows these topics (indented entries appear under the topic above them):

- Index
- Preferences
- Designer
- Visualizer
- Machine Control
  - G-Code Editor
  - Device Console
- CAM Tools
  - Tabbed Box Maker
  - Jigsaw Puzzle Generator
  - Laser Image Engraver
  - Speeds and Feeds Calculator
  - Spoilboard Surfacing
  - Create Spoilboard Grid
  - Gerber to G-Code
  - Drill Press
- Device Manager
- Device Config
- CNC Tools
- Materials
